# HomeLab GH – Ghana Home Lab Service

Fully operational **Next.js 14 App Router** medical lab booking platform.

Pixel-matched to the official design templates (logo, colors, medical background, Ghana badges, step icons, admin panel, client dashboard).

## Quick Start

```bash
npm install
npm run dev
```

Open **http://localhost:3000**

## Features
- Exact HomeLab GH logo (shield + DNA + test tube)
- Medical pattern login background
- Ghana flag badges throughout
- 4-step booking wizard + cart (localStorage)
- Protected client dashboard & My Results
- Full Admin panel (live price edit, status updates, results upload)
- Toast notifications
- Fully responsive

## Deploy on Render.com
1. Connect this GitHub repo
2. **Build Command**: `npm run build`
3. **Start Command**: `npm run start`
4. Add env vars from `.env`
